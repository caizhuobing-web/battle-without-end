# 无尽战域 / Battle Without End

手机优先的单机 PWA：自动战斗、装备刷宝、职业技能构筑、宠物养成与无尽星渊。

## Alpha 0.38 — 无尽后期整合版

### 0.35 基础循环修正

- 危险度自动升降：击败 Boss 自动升一级，任意战斗失败自动降一级，最低 T0。
- 危险度真实强化敌人和收益。
- 首次击败月背巨狼固定获得灰尾幼狼，并随机解锁战士、游侠或法师。
- Boss 狩猎每轮最多三次，失败保留本次伤害的 50%。
- Boss 基础周期从 T0 的 50 只普通怪起，每级危险度减少 5 只；时流法则与猎手罗盘可继续缩短至 0 只，形成连续 Boss 战。挑战失败后固定完成该次原周期的 50%（向上取整）再战。
- 自动融合仅保护变异 X；其他同物种普通宠物均可融合。
- 战斗金币产出提高约 40%。
- 装备商店每 30 分钟免费刷新 6 件装备，也可花金币立即刷新；普通至神话均可出现。

### Alpha 0.36 — 构筑深度

- 主动技能可设置使用条件：Boss、普通怪、残血、低生命和护盾目标。
- 技能拥有破甲、处决、连击、暴击、续航、守御、节奏、猎王等标签。
- 标签组合可激活破势处决、连击暴流、不息阵线、时序共鸣等联动。
- 提供三套构筑预设，保存职业、种族、装备、技能和宠物；职业切换可自动载入绑定构筑。

### Alpha 0.37 — 宠物正式版

- 每张地图只掉落一种固定区域宠物；普通怪低概率掉落该宠物，区域 Boss 也掉落同一种。
- 新增宠物图鉴与累计发现次数。
- 宠物在 Tier 3 和 Tier 6 各选择一次分支进化。
- 自动融合可以指定培养目标；只有变异 X 不会被自动消耗。

### Alpha 0.38 — 真正的无尽后期

- 星渊按层推进，敌人持续成长，Boss 按危险度周期出现并轮换机制。
- 普通层失败退回最近检查点；Boss 保留三次狩猎机会。
- 记录历史最高层，深度持续提高装备、神话和变异 X 概率。
- 每次转生提高世界阶级，使旧地图敌人与收益同步成长。
- 不增加新货币。

0.35 浏览器存档会自动迁移到 0.38，并保留既有身份、装备、宠物和进度。

直接通过 HTTPS 部署后，可在 iPhone Safari 中“添加到主屏幕”。
