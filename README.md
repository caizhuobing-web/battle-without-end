# 无尽战域 / Battle Without End

手机优先的单机 PWA：自动战斗、装备刷宝、职业技能构筑与宠物养成。

## Alpha 0.35 — 核心游戏性重构

- 危险度改为自动升降：击败 Boss 自动升一级，任意战斗失败自动降一级，最低为 T0。
- 危险度真实强化敌人的生命、攻击、防御和速度，并同步提高经验、金币与稀有掉落。
- 首次击败月背巨狼固定获得灰尾幼狼，并从战士、游侠、法师中选择第一个正式职业。
- Boss 狩猎每轮最多三次挑战；失败保留本次伤害的 50%，第三次失败后 Boss 完全恢复。
- 地图页显示 Boss 机制提示、当前危险度倍率和完整收益倍率。
- 自动宠物融合保护不同类型、S 以上资质、多项资质更高或战力更高的宠物。
- 0.34 浏览器存档会自动迁移至 0.35，并保留既有身份、装备、宠物和历史最高危险度。

直接通过 HTTPS 部署后，可在 iPhone Safari 中“添加到主屏幕”。
