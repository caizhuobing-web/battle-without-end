# 无尽战域 / Battle Without End

手机优先的单机 PWA：自动战斗、装备刷宝、职业技能构筑、终身宠物与世界难度突破。

## Alpha 0.42 — 构筑可视化与装备成长版

- 防御改为平滑减伤，避免“差一点被秒、多一点免伤”的断崖。
- 十四档难度对应七个装备成长带；神话规则不随阶级变化。
- 五张地图在非目标掉落时有55%概率启动定向重抽，而非只显示说明。
- 地图页新增构筑伤害贡献，区分追斩、鲜血、反伤、引爆、回响和宠物。
- 旧转生页面自动归一到角色页，转生执行入口永久失效。
- 修正旧存档的宠物变异特性类型并限制异常字段长度。

## Alpha 0.41 — 世界难度与终身伙伴版

### Build与终局重平衡（2026-08-08）

- 删除转生运行加成，角色等级硬上限为Lv.140。
- 普通至传说装备继续按角色适配评分优先；只有命名神话拥有改变战斗规则的力量。
- 首批6种Build：暴击连斩、血牛血爆、护盾反伤、灼烧引爆、冷却技能、宠物共战。
- 12件命名神话按每种Build两件核心配置，双核心会形成完整循环。
- 世界突破Boss使用固定模板，不再抽取日常Boss的随机稀有前缀。
- 离线结算保留玩家手动难度，但在等级过度领先时提供最低50%的经验效率保护。

- 五张地图改为永久等价值区域；地图只决定怪物、Boss、宠物物种与定向掉落。
- 删除运行中的地图危险度、星渊与转生加成，改为普通至折磨 X 共十四档手动世界难度。
- Boss 胜利只解锁下一难度，不自动切换；失败不会降低难度。
- Boss 进度按“地图＋难度”隔离，切换地图或难度不会串档。
- 新游戏增加灰尾幼狼、树灵幼芽、霜鳍幼兽三选一初契伙伴。
- 宠物阶级封顶10阶；同物种变异X可觉醒原宠并保留等级、阶级和培养记录。
- 停用定时装备商店、宠物仓扩建、灵宠精华及旧商店入口，核心装备来源回归战斗掉落。
- 手机主导航固定为战斗、角色、装备、宠物和地图五个入口。
- 0.41使用独立存档键；0.40存档只读取迁移，不覆盖原始存档。

## Alpha 0.40 — 决策反馈与架构版

- 三条基础职业路线都拥有完整高级版本与神话终点；法系新增神话职业“奥术主宰”。
- 职业一经解锁，其技能立即永久可用；切换到同路线高级职业会自动换上高级技能，并把低阶职业的最高熟练度继承给高级技能，不再要求回头修炼低级职业。
- Boss 的藏珍、镀金、天眷、星辉前缀加入实际战斗机制，不再只是掉率倍率。
- 战败后给出最多三条具体原因和换装/换技能方向；支持指定一套 Boss 专属构筑，遭遇 Boss 时自动切换，结束后恢复刷怪构筑。
- 新增阶段目标面板，奖励只使用金币与既有装备掉落，不引入新货币。
- 删除重复的随机装备行商，装备入口集中为刷怪掉落与 30 分钟定时商店。
- 将星渊、宠物扩展、战斗结果与地图面板改为核心钩子接入，移除多层函数包裹；补充 0.39→0.40 迁移和职业进阶回归测试。
- 按单人本地使用场景，本版不加入存档导入安全验证。

## 0.39 维护整合

- 浏览器运行脚本由 25 个整合为 4 个：核心、功能规则、0.39 系统和后台结算；样式由 3 个整合为 1 个。
- 删除历史 Base64/分片构建残留、旧测试页和重复的“修炼档案”轮询界面；技能进度统一在技能页查看。
- 游戏只在全部规则加载后启动，再读取和迁移存档，避免后置补丁与初始化互相覆盖。
- 修复旧进化形态虽然可融合、但可能丢失基础物种战斗机制的问题；战斗判断统一使用基础谱系。
- 重开游戏会清除旧后台结算时间戳；角色名进入 HTML 界面前会清理；移除没有玩法作用的年龄展示与废弃状态字段。
- 回归测试覆盖 0.38 存档迁移、宠物传承、进化谱系、Boss 重遇、Boss 前缀、宝箱怪、商店刷新、后台结算及长时间确定性战斗。

## Alpha 0.39 — 宠物养成与经济重平衡

- 宠物融合完整继承素材历次投入的进阶经验、当前进阶经验和等级经验；不新增可见的累计货币或属性。
- 进化宠物仍与基础形态属于同一谱系，可以继续互相融合升阶。
- 六种宠物在 Tier 3 / Tier 6 拥有不同名称、说明和实际战斗机制；四种类型也补齐定位、优势与短板说明。
- 战斗基础金币提高到旧版的 3.2 倍，转生继续提高金币收益。
- 普通战有 0.5% 概率遭遇宝箱怪；宝箱怪提供 100 倍基础金币，但不会占用或替代 Boss 战。
- Boss 新增藏珍、镀金、天眷、星辉四档稀有前缀；全域掉宝率分别提高至 1.25、1.50、2.00、3.00 倍，并同步提高金币与战斗强度。Boss 失败重遇时前缀保持不变。
- 移除灵魂；保留原有商店售罄自动刷新规则。
- 星渊入口降至 9,000 CP，并重平衡世界阶级的敌我成长。
- 合并后期补丁层，并加入宠物掉落、Boss 重遇、商店刷新、存档迁移与后台结算回归测试。

### 0.35 基础循环修正

- 危险度自动升降：击败 Boss 自动升一级，任意战斗失败自动降一级，最低 T0。
- 危险度真实强化敌人和收益。
- 首次击败月背巨狼固定获得灰尾幼狼，并随机解锁战士、游侠或法师。
- Boss 狩猎每轮最多三次，失败保留本次伤害的 50%。
- Boss 基础周期从 T0 的 50 只普通怪起，每级危险度减少 5 只；时流法则与猎手罗盘可继续缩短至 0 只，形成连续 Boss 战。挑战失败后固定完成该次原周期的 50%（向上取整）再战。
- 自动融合仅保护变异 X；其他同物种普通宠物均可融合。
- 战斗金币产出提高约 40%（已被 0.39 的 3.2 倍基础金币取代）。
- 装备商店每 30 分钟免费刷新 6 件装备，也可花金币立即刷新；普通至神话均可出现。

### Alpha 0.36 — 构筑深度

- 主动技能可设置使用条件：Boss、普通怪、残血、低生命和护盾目标。
- 技能拥有破甲、处决、连击、暴击、续航、守御、节奏、猎王等标签。
- 标签组合可激活破势处决、连击暴流、不息阵线、时序共鸣等联动。
- 提供三套构筑预设，保存职业、种族、装备、技能和宠物；职业切换可自动载入绑定构筑。

### Alpha 0.37 — 宠物正式版

- 宠物仅由区域 Boss 掉落；每张地图固定对应一种宠物，普通怪不会掉落宠物。
- 新增宠物图鉴与累计发现次数。
- 宠物在 Tier 3 和 Tier 6 各选择一次分支进化。
- 自动融合可以指定培养目标；只有变异 X 不会被自动消耗。

### Alpha 0.38 — 真正的无尽后期

- 星渊按层推进，敌人持续成长，Boss 按危险度周期出现并轮换机制。
- 普通层失败退回最近检查点；Boss 保留三次狩猎机会。
- 记录历史最高层，深度持续提高装备、神话和变异 X 概率。
- 每次转生提高世界阶级，使旧地图敌人与收益同步成长。
- 不增加新货币。

  0.35—0.39 浏览器存档会自动迁移到 0.40，并保留既有身份、装备、职业熟练度、宠物阶级、进阶经验、等级和进度。
