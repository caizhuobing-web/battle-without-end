# 《万变之种》文案规范

所有游戏内文字以本文件为准。新增条目先查术语表，再按句式写。

## 1. 世界观一句话

一颗落进培养液的种子，靠吞噬与变异，长成它自己选择的样子。

叙述口吻是一位冷静的观察者在写实验记录：短句，陈述事实，不喊口号，不用感叹号，不用网络用语。

## 2. 术语表（同一概念只用一个词）

| 概念 | 统一用词 | 禁用 |
| --- | --- | --- |
| 一次完整游玩 | 一局 | 一把、一轮 |
| 局内随机强化 | 变异 | 天赋、词条、升级项 |
| 路线分支 | 进化 | 转职、进阶 |
| 进化后的样子 | 形态 | 职业、种族 |
| 主动攻击手段 | 技能 | 武器、招式 |
| 流派标签 | 物理、剧毒、火焰、雷电、冰霜、鲜血、虫群、甲壳 | 其他叫法 |
| 局外货币 | DNA | 基因点、金币 |
| 局外永久成长 | 基因强化 | 天赋树、科技 |
| 难度档位 | 培养皿（一号皿到六号皿，各有名字） | 关卡、难度 |
| 一批敌人 | 波 | 关、层 |
| 首领敌人 | 领主 | BOSS、头目 |
| 自动游玩 | 挂机 | 托管、自动战斗 |
| 属性 | 生命上限、生命回复、护甲、闪避率、伤害、攻击速度、暴击率、暴击伤害、范围、吸血 | 攻速、暴伤、回血等缩写 |
| 持续伤害状态 | 中毒（按层）、点燃 | 上毒、灼烧 |
| 控制状态 | 减速、冻结 | 冰冻、定身 |

## 3. 命名规则

| 类别 | 规则 | 例 |
| --- | --- | --- |
| 形态 | 2 到 4 字，一阶是物种名，二阶加特征，三阶是称号。全部是"生物"，不出现人类职业 | 猎牙兽、影爪豹、瞬杀之影 |
| 技能 | 4 字，前两字是性质，后两字是器官或动作 | 撕裂利爪、连锁电弧 |
| 变异 | 2 到 4 字，一律是器官、组织或生理现象，不用游戏黑话 | 毒腺、角质硬化、第二心脏 |
| 敌人 | 3 字，"特征 + 体" | 游荡体、重甲体 |
| 基因强化 | 2 到 4 字名词 | 体质、利齿 |

## 4. 描述句式

效果描述只写玩家能验证的事实，按固定顺序：**条件，效果，数值**。没有条件就直接写效果。

- 数值一律带符号和单位：`伤害 +10%`、`护甲 +9`、`每秒回复 +1.5 生命`
- 属性名与数值之间一个空格，多条效果用顿号以外的逗号分隔
- 一条描述不超过两行（手机宽度约 26 字一行）
- 条件用"时"结尾：`中毒的敌人死亡时，把 50% 的中毒层数传给附近敌人`
- 不写感受词（强大、恐怖、大幅），只写数

## 5. 界面文字

| 场景 | 规则 | 例 |
| --- | --- | --- |
| 按钮 | 动词开头，说清点了会发生什么。同一动作全程同名 | 开始培养、继续培养、再培养一局、购买 |
| 确认 | 写出动作和后果，不写"确定吗" | 放弃本局（已获 DNA 照常结算） |
| 空状态 | 这是什么，为什么空，怎么开始 | 还没有变异。升级后从三个变异里选一个。 |
| 错误 | 发生了什么，怎么办。不道歉 | 存档码无法识别，存档未改动。请检查是否复制完整。 |
| 结算 | 先结论再数据 | 培养终止于第 12 波 |
| 提示 | 一句话，不重复界面上已有的信息 | |

## 6. 标点与格式

- 不用感叹号，不用省略号，不用破折号
- 数字与中文之间留一个空格
- 界面标签不加冒号结尾
