# 《万变之种》文案规范

所有游戏内文字以本文件为准。新增条目先查术语表，再按句式写。

## 1. 世界观一句话

一颗种子沉进一口没有底的深井。越往下越危险，能带回去的东西也越好。它靠吞噬与变异活下来，再决定什么时候带着物资回到井口。

叙述口吻是一位冷静的观察者在写实验记录：短句，陈述事实，不喊口号，不用感叹号，不用网络用语。

## 3. 命名规则

| 类别 | 规则 | 例 |
| --- | --- | --- |
| 形态 | 2 到 4 字，一阶是物种名，二阶加特征，三阶是称号。全部是"生物"，不出现人类职业 | 猎牙兽、影爪豹、瞬杀之影 |
| 技能 | 4 字，前两字是性质，后两字是器官或动作 | 撕裂利爪、连锁电弧 |
| 变异 | 2 到 4 字，一律是器官、组织或生理现象，不用游戏黑话 | 毒腺、角质硬化、第二心脏 |
| 敌人 | 3 字，"特征 + 体" | 游荡体、重甲体 |
| 基因强化 | 2 到 4 字名词 | 体质、利齿 |

## 4. 描述句式

效果描述只写玩家能验证的事实，按固定顺序：**条件，效果，数值**。没有条件就直接写效果。

- 数值一律带符号和单位：`伤害 +10%`、`护甲 +9`、`每秒回复 +1.5 生命`
- 属性名与数值之间一个空格，多条效果用顿号以外的逗号分隔
- 一条描述不超过两行（手机宽度约 26 字一行）
- 条件用"时"结尾：`中毒的敌人死亡时，把 50% 的中毒层数传给附近敌人`
- 不写感受词（强大、恐怖、大幅），只写数

## 5. 界面文字

| 场景 | 规则 | 例 |
| --- | --- | --- |
| 按钮 | 动词开头，说清点了会发生什么。同一动作全程同名 | 下井、继续下潜、上浮、再下一次井 |
| 确认 | 写出动作和后果，不写"确定吗" | 放弃本局（已获 DNA 照常结算） |
| 空状态 | 这是什么，为什么空，怎么开始 | 还没有变异。升级后从三个变异里选一个。 |
| 错误 | 发生了什么，怎么办。不道歉 | 存档码无法识别，存档未改动。请检查是否复制完整。 |
| 结算 | 先结论再数据 | 回到井口；留在了井里 |
| 提示 | 一句话，不重复界面上已有的信息 | |

## 6. 标点与格式

- 不用感叹号，不用省略号，不用破折号
- 数字与中文之间留一个空格
- 界面标签不加冒号结尾

## 7. 借鉴边界

下潜、分层、越深越好的物资、上浮有代价，这些是玩法结构，可以借鉴。任何现有作品的名称、角色、专有名词、台词和美术一律不用。本作的名词只用上面术语表里的。
