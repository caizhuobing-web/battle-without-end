# 《万变之种》美术规范

所有画面与界面改动以本文件为准。PM 复审时逐条对照。

## 1. 一句话方向

一口深井的横截面：玩家透过一台老式仪器的圆形视窗，看一颗种子在井水里吞噬、变异、进化，并一层层下潜。像素风，低分辨率，硬边，无渐变。

## 2. 分辨率与像素纪律

| 项 | 规定 |
| --- | --- |
| 战斗画布 | 内部固定 192×192 像素，整倍或近整倍放大，`image-rendering: pixelated` |
| 坐标 | 所有绘制坐标取整，禁止半像素 |
| 抗锯齿 | 禁止。画布关闭平滑，禁用渐变、模糊、半透明叠色 |
| 描边 | 所有生物与敌人 1 像素深色外描边（`墨` 色） |
| 明暗 | 统一左上打光，三段色：亮面、本色、暗面，由生成器按同一规则自动计算 |
| 过渡 | 需要"半透明"时用棋盘格抖动，不用 alpha |
| 圆角 | 界面一律直角，面板用 2 像素硬边框加 1 像素高光线 |

## 4. 形体语言

| 对象 | 规定 |
| --- | --- |
| 玩家生物 | 画面中最大、最亮的东西。一阶 24 像素，二阶 28，三阶 32。永远居中 |
| 掠食系 A | 尖刺、獠牙、斜眼。轮廓带角 |
| 元素系 B | 触须、单颗发光核心。轮廓柔软 |
| 群殖系 C | 孢囊、多眼。轮廓成簇 |
| 同系亚种 | 共用体型，用换色区分；终极形态再加一圈环绕粒子 |
| 敌人 | 全部偏珊瑚红与冷灰，绝不使用玩家流派色，保证一眼分清敌我 |
| 敌人识别 | 靠轮廓区分：游荡体圆、迅捷体箭头、重甲体六边、喷吐体带口器、分裂体双球、自爆体带刺闪烁、领主带冠 |
| 精英 | 琥珀色外描边 |

## 5. 特效层级（从低到高，上层永远不被下层遮挡）

1. 培养皿底与刻度
2. 毒云等地面效果（棋盘格抖动）
3. 敌人
4. 幼虫、弹体、环绕物
5. 玩家生物
6. 命中特效（爆炸圈、电弧、火舌）
7. 伤害数字（3×5 像素数字，暴击为琥珀色并放大一倍）
8. 界面覆盖层（领主血条、提示）

同屏伤害数字有上限，持续伤害只抽样显示，保证主体不被数字淹没。

## 6. 字体

全局只用一种字体：Fusion Pixel 12px Proportional SC（SIL OFL 1.1，随游戏分发子集文件）。字号只允许基准字号及其 2 倍、3 倍。不混用系统字体，不使用 emoji 作为图标。

## 7. 界面组件

| 组件 | 规定 |
| --- | --- |
| 面板 | 茄皮底，淤青 2 像素边，内侧上沿 1 像素高光 |
| 按钮 | 主按钮琥珀底墨字；次按钮淤青边；按下时整体下移 2 像素，无缩放动画 |
| 进度条 | 分段像素条，无圆角，无渐变 |
| 稀有度 | 普通骨白边，稀有电青边，史诗群紫边，进化琥珀边 |
| 动效 | 只保留有信息量的：选项卡片入场一次、进化时全屏闪一次、数值条变化。禁止装饰性循环动画 |
