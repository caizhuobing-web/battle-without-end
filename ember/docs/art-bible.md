# 《万丈深渊》美术规范

所有画面与界面改动以本文件为准。PM 复审时逐条对照。格式沿用 `evo/docs/art-bible.md`。

## 1. 一句话方向

冷的世界里唯一的暖色是火。地面是灰白的雪和铁，渊隙越往下越暗、越偏离人能呼吸的颜色；能核、炉火和人身上的灯是画面里仅有的暖光。像素风，低分辨率，硬边，无渐变。

## 2. 分辨率与像素纪律

| 项 | 规定 |
| --- | --- |
| 主画布 | 内部固定 180×112 像素，只按整数倍放大（360 宽手机正好 2 倍铺满），整倍或近整倍放大，`image-rendering: pixelated` |
| 坐标 | 所有绘制坐标取整，禁止半像素 |
| 抗锯齿 | 禁止。画布关闭平滑，禁用渐变、模糊、半透明叠色 |
| 描边 | 所有人物与敌人 1 像素外描边（`煤` 色） |
| 明暗 | 统一左上打光，三段色（亮面、本色、暗面），在精灵网格里逐像素手工指定，不用自动描边算法 |
| 派生色 | 亮面 = 本色与雪白 6:4 混合，暗面 = 本色与煤 6:4 混合；场景里的远景、火光映雪等也只用两种色板色按固定比例混合 |
| 过渡 | 需要"半透明"时用棋盘格抖动，不用 alpha |
| 圆角 | 界面一律直角，面板 2 像素硬边框加 1 像素高光线 |

## 4. 形体语言

| 对象 | 规定 |
| --- | --- |
| 小队 | 三人，每人约 18 像素高，腰间一盏小灯（余烬色 1 像素）。职业靠轮廓区分：猎核者兜帽长枪、护卫者头盔大盾、御炉者背炉罐持喷口 |
| 敌人 | 全部敌灰系，绝不使用职业色和资源色 |
| 敌人识别 | 靠轮廓：冻鼠群矮小拖尾、白鬣低伏长身、群鸣蝠和灼雾蛾悬空扇翅（两帧）、攀壁蜥贴地长尾、拟岩虫是带一排牙的石块。三个据点首领各有一张原尺寸精灵（老鬣首带鬃刺、井口守兽展翼带角、雾窟巨兽背上有气孔），不放大普通敌人 |
| 破甲标记 | 被猎核者破甲的敌人外描边换成猎核者色 |
| 场景 | 每层一张可横向循环的背景：远景剪影、岩顶、地面、每层独有的东西（霜根廊冰棱与冻根，回声井岩架与垂绳，沸雾窟矿物烟囱与气孔）。旧补给线的桩和绳贯穿三层，修好的路段桩上亮灯。走路时背景滚动 |
| 灯光 | 离小队越远越暗，用煤色抖动点阵分三档，不用半透明 |
| 聚落 | 夜空、雪山、五间屋子、雪地、火塘、补给线入口。亮窗数和火焰高度、火光范围都是炉温的读数；入口的灯是补给线进度的读数 |
| 节点图标 | 8×8 字符串图标：敌情、货箱、锚点、热泉、据点、未知。未知节点只画问号 |

## 5. 特效层级（从低到高）

1. 层背景
2. 地面效果（雾、冰，用棋盘格抖动）
3. 敌人
4. 弹体、护盾
5. 小队
6. 命中特效
7. 伤害数字（3×5 像素数字）
8. 界面覆盖层

## 6. 字体

全局只用 Fusion Pixel 12px Proportional SC（SIL OFL 1.1，复用 `evo/font.woff2` 的子集流程，文案定稿后重新裁剪）。字号只允许基准及其 2 倍、3 倍。不用 emoji 作图标。

## 7. 界面组件

| 组件 | 规定 |
| --- | --- |
| 面板 | 铁灰底，锈边 2 像素边，内侧上沿 1 像素高光 |
| 按钮 | 主按钮余烬底煤字；次按钮锈边；按下整体下移 2 像素 |
| 资源条 | 分段像素条：氧气氧青、负重负重褐、炉温炉红 |
| 弹窗 | 煤色实底，不用半透明遮罩 |
| 动效 | 人物呼吸起伏 1 像素、出手前冲 3 像素、受击闪白、会飞的敌人扇翅。环境粒子每层一种且不超过 12 个：聚落和霜根廊飘雪、回声井滴水、沸雾窟雾带和火星。界面本身不做装饰性循环动画 |
