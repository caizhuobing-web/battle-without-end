# 《万丈深渊》改版方向提案（待审核，未动工）

写于 2026-11-25。提案人：开发方（Claude）。状态：用户初步认可（「我觉得不错」），但要求动工前做多角度的二次审核，确认方向正确。本文件只描述方向，不是最终设计。

## 用户说过的话（原话，是判断方向的唯一依据）

1. 交接说明（`docs/new-game-handoff.md`）：做一款新的单机游戏，手机浏览器可玩、偏挂机、有路线选择和多种搭配，长期目标是 Steam 品质。世界观见 Drive《Abyss_Story_Overview_ZH_v0.10.md》（永冬、炉火、下潜取能核、带回才算数）。美术像素风。只借结构，不用任何现有作品的名称、角色、专有名词。
2. 「你自己决定，我只要一个成品结果。」
3. 「这个美术风格有点粗糙呀，是否可以优化一下。」「网上不是有免费的像素风格的素材吗？是否可以考虑使用。」
4. 「不要三个角色，只要一个角色，另外角色做成衣服一样，可以换，也可以升级，每个衣服自带特性，要配合特性来构筑，打怪会掉装备，或者技能或者什么东西。」
5. 「我觉得你得先暂停，你整理一下游戏玩法，先整理不要急着做。」

## 现状（提交 9e7881e）

一个主角；三套行装（猎核装打大型敌人、御炉装打成群敌人、护卫装最稳）可换、可升级、可进阶；打怪掉配件（14 种、三档品质、装 3 件）和技艺（6 个、带 2 个）。下潜是在分叉路线图上选节点，遇敌三选一（战斗、绕行、撤退），**战斗全自动、只显示推演结果和简单回放**。限制资源有氧气、负重、生命；聚落有炉火（炉温）、工坊（氧罐、护具、背架各三级）、补给线三段（修好后自动产出能核）、终局兽潮。另有耐力、散热、底火、久战耗氧、备用行装、战术开关等细则。

独立评审记录：三人小队版 57、74、77 分；单主角版 62 分（`ember/docs/pm-review-r3.md`），核心结论是「配合特性来构筑没有成立」。之后加了备用行装等规则（9e7881e），尚无评审结论。

开发方自己认为的问题：
- 同时有三种玩法在抢位置：下潜撤离、构筑刷装备、聚落经营加挂机。骨架是按第一种和第三种搭的，构筑是后接的。
- 战斗全自动且看不见，装了新装备只是推演百分比变几个点，没有变强的反馈。
- 系统多而浅，新手要理解的概念太多。
- 挂机在线时太弱（每分钟 0.5 到 3 个能核）、离线时太强（修好第一段后离线 8 小时得 240 个，够修第二段）。
- 备用行装、久战耗氧、同名配件限装等规则是为了让数值对比成立而加的，没有问过用户。

## 提案

**总方向：砍掉一半系统，把游戏收拢成「一个人、换行装、刷装备」，并把战斗做成看得见的。**

1. **主心骨定为构筑刷装备。** 下潜是刷的场所，聚落是整理装备的地方。
2. **战斗改成看得见的实时自动战斗。** 主角自己打，敌人一波波来，技艺自动放，有伤害数字和特效。玩家的操作只有：随时撤退，和手动放一个冷却较长的大招。可以改用仓库里上一款《万变之种》（`evo/sim.js`、`evo/pixel.js`）已有的实时自动战斗。
3. **行装做深，只留三套。** 每套一个自带特性加一个专属大招；升级到特定等级时三选一拿天赋，共三次。去掉备用行装、姿态开关、模式开关。
4. **装备简化成三个槽**（武器、护具、饰品），每件一到两条词条；稀有装备带一条改变打法的词条。工坊三件套并进装备。
5. **只留氧气一个限制。** 砍掉负重、炉温、耐力、散热、底火、久战耗氧。背包改成固定格数。
6. **聚落只留三页**（行装、装备、出发）。补给线保留为章节进度（清一层首领、修一段）。挂机重做：修好的层可以派常规队伍去刷，在线和离线同一速度，产出能核和低档装备，设上限。兽潮保留为首版最终首领战。
7. **保留不动：** 世界观、三层和敌人、美术与素材、路线图选节点、存档与测试框架。

代价：战斗和成长基本重写，界面重排，之前的数值作废。

## 提案人没把握的地方

- 「偏挂机」和「看得见的实时战斗」是否冲突：实时战斗需要玩家盯着看，挂机需要玩家不用看。
- 砍掉负重和炉温后，世界观里「带回才算数」「炉火将熄」的味道还剩多少。
- 用《万变之种》的战斗来改，会不会把那款游戏已知的问题（评审 59 分，内容量不足）一起带过来；用户当时明确选择了「另起新游戏、不在万变之种上改」。
- 手动大招是否必要，会不会变成半吊子的动作游戏。
- 这是开工以来第三次大改方向，范围是否仍然太大。
