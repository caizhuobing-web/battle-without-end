# 《万丈深渊》文案规范

所有游戏内文字以本文件为准。新增条目先查术语表，再按句式写。格式沿用 `evo/docs/copy-guide.md`。

## 1. 世界观一句话

永冬里，灰炉屯的炉火只够再烧几天。你一个人沿一条废弃的补给线下到渊隙，去换回能让大家熬过冬天的能核，并且活着回来。

口吻是一位队长的行程日志：短句，写看到的和做了的，不喊口号，不用感叹号，不用网络用语。情绪通过事实表达，例如"炉温又降了一格"，而不是"情况危急"。

## 3. 命名规则

| 类别 | 规则 | 例 |
| --- | --- | --- |
| 敌人 | 2 到 4 字，"特征 + 动物类名"，不用现有作品里的怪物名 | 冻鼠群、白鬣、群鸣蝠、攀壁蜥、灼雾蛾、拟岩虫 |
| 材料 | 2 到 3 字，写清它是什么部位或物质 | 冻筋、层甲骨、韧骨板、赤核、导热丝 |
| 装备 | 2 到 4 字，器物名，等级用"旧、新、精"前缀 | 旧氧罐、新背架、精制护具 |
| 地名 | 2 到 3 字，写地貌或一个可见特征 | 霜根廊、回声井、沸雾窟 |
| 人名 | 单字或两字，像一个人的小名 | 苇 |

## 4. 描述句式

效果描述只写玩家能验证的事实，顺序为**条件，效果，数值**。

- 数值一律带符号和单位：`氧气 +6`、`负重 -2`、`攻击 +15%`
- 一条描述不超过两行（手机宽度约 26 字一行）
- 条件用"时"结尾：`超重时，每步氧气 -1`
- 不写感受词（强大、恐怖、大幅），只写数

## 5. 界面文字

| 场景 | 规则 | 例 |
| --- | --- | --- |
| 按钮 | 动词开头，说清点了会发生什么。同一动作全程同名 | 出发下潜、战斗、绕行、撤退、归返 |
| 确认 | 写出动作和后果，不写"确定吗" | 撤退（回程需要氧气 6，当前 9） |
| 空状态 | 这是什么，为什么空，怎么开始 | 库房里没有材料。下潜时打倒敌人会带回材料。 |
| 错误 | 发生了什么，怎么办。不道歉 | 存档码无法识别，存档未改动。请检查是否复制完整。 |
| 结算 | 先结论再数据 | 归返；丢下了 4 个能核 |

## 6. 标点与格式

- 不用感叹号，不用省略号，不用破折号
- 数字与中文之间留一个空格
- 界面标签不加冒号结尾

## 7. 借鉴边界

下潜、分层、越深越好的收获、回程有代价、聚落建设、挂机产出，这些是玩法结构，可以借鉴。任何现有作品的名称、角色、专有名词、台词和美术一律不用。本作的名词只用上面术语表里的。
